# Davis Future Planning LLC 🏡💰

> *"Everyone In Your Household Should Have Excellent Credit"*

A modern, high-performance credit repair and financial planning website built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS 4**.

## About

Davis Future Planning LLC is a credit repair and financial advisory service founded by Paranda Davis. With over **8 years of experience**, Davis Future Planning helps individuals and families improve their credit scores through personalized strategies, dispute processes, and financial education.

### Services

| Package | Price |
|---|---|
| **Basic Credit Repair** | $100/mo |
| **Credit Beast Package** | $499.99 down + $89.99/mo |

Both packages include one-on-one credit evaluation, personalized dispute strategies, and coverage across all three credit bureaus (Equifax, Experian, TransUnion).

### Pages

- **Home** — Showcases services, client testimonials, video success stories, and the Cornbread children's book series
- **Get Started** — Pricing details and enrollment via JotForm
- **Credit Building Center** — Curated resources (credit builder cards, self lender accounts, tradeline services, rent reporting, and more)
- **Check My Credit** — Guides users on how to obtain and review their credit reports
- **FAQ** — Credit score ranges, scoring factors, and common credit repair questions
- **Privacy Policy** — Data handling and privacy practices

### Author / Publisher

Paranda Davis is also the author of:
- **Cornbread** — A children's book series teaching financial literacy to young readers ([cornbreadkidsbooks.com](https://www.cornbreadkidsbooks.com/))
- **How To Get An 800 Credit Score For Rookies** — A credit-building boot camp guide ([Amazon](https://www.amazon.com/How-Get-Credit-Score-Rookies/dp/0692071377))

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Other Commands

| Command | Description |
|---|---|
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Deployment

The site can be deployed to any platform that supports Next.js (Vercel, Netlify, or a custom Node.js server). For the simplest deployment, use [Vercel](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme).
